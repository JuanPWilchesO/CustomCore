# Tutoriales

> ⚠️ **Esta carpeta se restaura desde el jar en cada arranque.** No guardes aquí archivos
> propios ni edites estos: se sobrescriben en la siguiente actualización. Para tus notas,
> usa otra carpeta.

Guias paso a paso. Se leen en orden; cada una anade una funcionalidad sobre la anterior.

| Tutorial | Que aprendes |
|---|---|
| `01-primer-mob.md` | crear un mob, invocarlo, recogerlo y re-desplegarlo |
| `02-equipo-y-encantamientos.md` | equipar por slot, encantamientos vanilla y custom, objetos con NBT |
| `03-skills.md` | efectos, objetivos y avisos de skill |
| `04-faccion-y-spawner.md` | mobs de servidor, facciones, actitud y reaparicion |
| `05-objeto-con-nbt.md` | el catalogo de objetos con NBT |
| `06-disfraz-sonidos-y-colores.md` | apariencia, sonidos y estilo por jugador o team |
| `07-libro-y-mejoras.md` | el libro de inspeccion y un item de mejora |
| `08-monturas.md` | una montura: aspecto, efectos, paso helado y cupo |
| `09-pociones-crafteables.md` | pociones bebibles, arrojadizas y persistentes con receta |
| `10-control-de-masas-pvp.md` | stun, root, silence, disarm, escudo y trinket |
| `11-interfaz-y-avisos.md` | boss bars, cooldowns, titulos y reglas de chat |

Los ejemplos numerados que se copian solos en `plugins/CustomCore/mobs/` son el punto de
partida: abrelos en orden, tienen comentarios que explican cada clave.

Para la referencia completa, mira `../docs/README.md`.
